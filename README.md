# The Finds Co Store

Full-stack e-commerce store built with Vite, React, TypeScript, Tailwind CSS, and Supabase.

## Features

- Product catalog with categories, search, and detail pages
- Shopping cart and checkout flow
- User authentication (login / register)
- Admin dashboard for products, orders, categories, customers, analytics, and CMS
- Supabase backend with RLS and migrations

## Getting Started

1. Clone the repo
2. Copy `.env.example` to `.env` and fill in your Supabase credentials
3. `npm install`
4. `npm run dev`

See the full README in the original project for more details.
